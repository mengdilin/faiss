# NumPy free-threaded port — issues & PRs (complete)

NumPy is the reference C-extension port. **197 items** (143 PRs + 54 issues), ~2 years, ongoing.

- **Epic / tracking issue:** [#26157 — ENH: Support free-threaded python build (tracking issue)](https://github.com/numpy/numpy/issues/26157)
- **Canonical live list (all items):** <https://github.com/numpy/numpy/issues?q=label%3A%2239+-+free-threading%22>
- **TSan on ARM Mac is broken (why we use Linux):** [#27136](https://github.com/numpy/numpy/issues/27136)

## Reading order (the steps NumPy took)
0. Plan & tooling → 1. Build/import on nogil → 2. Declare module FT-capable → 3. Refcounting (borrowed→strong ref) → 4. Global state (disable/lock/thread-local/context-var) → 5. Locking primitives → 6. Fix the data races (the long tail) → 7. Performance/contention → 8. Testing & sanitizers → 9. CI & dual wheels → 10. Stable ABI for FT (abi3t/opaque) → 11. Docs.

The full list below is grouped by the label's own prefixes (guarantees completeness); each entry maps to one of the steps above.
